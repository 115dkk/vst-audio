# VstAudio

This release reserves the package ID for the planned .NET bindings of
[vst-audio](https://github.com/115dkk/vst-audio), a Rust library that hosts
VST2 and VST3 plugins in separate worker processes on Windows, macOS and Linux.
It contains no plugin hosting yet.
